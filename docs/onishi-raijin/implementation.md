# 大西雷神 — extra2の試作

2026-09-08。風神の「子音を保持して母音を入力する」仕組みを、右手の大西配列へ取り入れた独自実装です。作者の公式雷神配列を移植したものではありません。

現在の設定は [キーマップHTML](../keymap/index.html) のレイヤー8・9で確認できます。

## 入る・戻る

| 場所 | キーの位置 | 新しい動作 |
| --- | --- | --- |
| system（L6） | 旧「L7 Toggle」・通常のK位置（#4） | 大西雷神 L8へ移動：`&to 8` |
| system（L6） | 旧「INS」・通常のW位置（#5） | 通常配列へ復帰：`&to 0` |
| 大西雷神（L8） | 左Enter親指（#28） | systemへ移動 |
| 大西雷神（L8） | 左Delete親指（#29） | 通常配列へ直接復帰 |
| 編集補助（L9） | 右上Y位置（#7） | systemへ移動 |
| 編集補助（L9） | 左親指 #28 / #29 | system / 通常配列へ移動 |

通常配列からは **Enter親指を保持 → Space親指も保持 → systemのK位置を押す** と入れます。入ったら移動に使ったキーをすべて離してください。

右手だけで戻る場合は、**子音を離す → Backspace親指を保持 → Y位置でsystem → W位置で通常配列** です。補助への移動は180ms保持、または次の右文字キーを押すことで確定します。移動には排他的な `&to` を使い、L8が上に残って戻り先を隠す問題を避けています。

## 基本の配列

| 段 | 右手の並び |
| --- | --- |
| 上 | K W R Y |
| 中 | G T N S H P |
| 下 | D M Z B |
| 親指 | Backspace・補助・U / Space・母音 |

通常の大西配列の右側を基本とし、J位置をZにしています。じ・じゃは `zi` / `zya` を使います。

子音は押した瞬間に1回送られます。保持したまま次の母音キーを押すと、母音を送ります。ホーム段の長押し修飾や、文字の長押しリピートは使いません。

| 子音保持中に押す位置 | 出力母音 |
| --- | --- |
| T（#15） | O |
| N（#16） | A |
| S（#17） | I |
| H（#18） | E |
| R（#6） | U |

同じ指で押しにくい母音は **Space親指** に移します。保持する子音のグループにより O / A / I / E が変わります。**Backspace親指** は子音保持中なら常に U です。

| 保持する子音 | Spaceの出力 |
| --- | --- |
| K W G T D | O |
| R N M | A |
| Y S Z | I |
| H P B | E |

母音だけを入力するときは **Spaceを先に保持してから母音の位置を押す**。Spaceだけを押して離すと通常のSpaceになります。

## 最初に試す入力

OSのIMEをローマ字入力でONにしてから試してください。配列の切り替えではIMEの状態は変えません。

| 入力 | 操作 |
| --- | --- |
| か `ka` | Kを保持 → N位置を押す → 全部離す |
| こ `ko` | Kを保持 → Spaceを押す → 全部離す |
| き `ki` | Kを保持 → S位置を押す → 全部離す |
| な `na` | Nを保持 → Spaceを押す → 全部離す |
| る `ru` | Rを保持 → Backspaceを押す → 全部離す |
| あ `a` | Spaceを先に保持 → N位置を押す → 全部離す |
| きょう `kyou` | K → Yを保持 → Kを離す → T位置でO → BackspaceでU → 全部離す |
| ん `nn` | Nを2回押す、または編集補助のB位置 |

1音節ごとに子音を離してください。前の子音を保持したまま次の音節に進むと、T/N/S/H/R位置は母音になります。複数の子音が重なったときは最後に押した子音が優先され、離すと残った子音へ戻ります。

## 編集補助（extra3 / L9）

子音がない状態でBackspaceを先に保持すると使えます。短い単独タップはBackspaceです。補助中はBackspace親指を離すとL8へ戻ります。

| 段 | 右手の並び |
| --- | --- |
| 上 | Esc / V / Enter / system |
| 中 | X / ← / ↓ / ↑ / → / F |
| 下 | , / . / - / ん（nn） |

X/F/Vは補助で1回送り、いったん全部離してからSpace先押しの母音入力を続けます。例：ふ は補助のF → 全解放 → Space保持＋R位置（U）。数字・英文・通常のショートカットは通常配列で入力します。

両方の右親指を同時に押す操作は割り当てていません。母音待ち・補助待ちの途中で反対の親指を押した場合は、不要なSpace/Backspaceを抑止します。

## 実装と検証

- `fish.keymap` にL8/L9の配列と `&rj` の設定を追加。既存コンボはL0〜L7に限定し、子音と母音の重なりでIME切替やbootloaderが発火するのを防ぎます。
- `src/raijin/` はZMKに依存しないCの入力状態処理。`tests/raijin/run.sh` で入力例・解放順・タイマー・初期化を検証します。`run_adapter.sh` は実際の接続コードをstub環境で動かし、補助の初回キー転送と切断後の押し直しなどを確認します。
- `src/behaviors/behavior_onishi_raijin.c` はZMKとの接続。短いキー押下・解放を対にして送出し、モード退出・スリープ・接続変更時に内部状態を消去します。
- `zephyr/module.yml` によってこのリポジトリ自身をZMKの追加モジュールとして使用します。既存の公式GitHubビルドworkflowはモジュールを自動検出します。
- 現行HTMLは独自behaviorの文字と親指の役割、L8→L9の条件付き経路を表示します。ブラウザーは書き込み済み実機の状態を取得しません。

実機でのBluetooth入力、IMEの変換、打鍵のしやすさは別途確認が必要です。右手操作でも左半分が通信上の親機なので、左右とも接続して使用します。

左右とsettings_resetのビルドは成功しています。[ビルド・テストの記録](build-validation.md)に検証した版と結果を残しました。書き込み用の左右UF2は `artifacts/raijin/` にあります。

## 初期設計との差分

初期の [設計書](design.md)・[操作デモ](index.html) はK+S+Mコンボでの入口を提案していました。今回の実装ではユーザー指定のsystemキーから入り、右手の補助からsystemへ戻ります。左親指にもsystemと通常配列への出口を用意しています。
