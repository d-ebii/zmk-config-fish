02何を取り入れるか

子音の保持が、母音への入口

風神は、子音を押したまま次のキーを母音にします。本案は大西の右手14文字のうち13位置を残し、左手の母音を鏡写しに重ねます。

K を保持 → N の位置 = ka

同じ指の母音は、親指へ

可変Spaceという考え方を採用。人差し指→O、中指→A、薬指→I、小指→E。もう一方の親指は、子音保持中だけ固定Uです。

K を保持 → Space = ko

両手と片手を、使い分ける

大西は既に左右で母音・子音を分けています。常用面を置き換えず、8に日本語の右手モード、9に編集面を用意します。速度向上率は未検証です。

0 通常 ⇄ 8 日本語 ＋ 9 補助

原典の仕組み: 本城靖大さんの風神・雷神の紹介。これは通常のローマ字2打を1打にする方式ではなく、片手で母音面へ移るための操作を減らす考え方です。

04母音と親指の決め方

左手の感覚を、右手へ映す

右手の位置母音可変Spaceの対象

指の担当は物理座標に基づく仮定です。特に内側キーの運指は実機で確認します。母音のUはW位置ではなく、左Uの鏡像に当たるR位置です。

2つの親指、押す順序で使い分け

31 · Space側
単独タップはSpace。先に保持すると単独母音を入力。子音の後に押すと指別の母音を入力します。

30 · Backspace側
単独タップはBackspace。先に保持して別キーを押すと補助9へ。子音の後に押すとUです。

補助への保持判定は180msの仮値。先に別キーを押したときは待たずに補助へ進みます。親指2キーの同時押しは使いません。

05入る・編集する・戻る

0 通常の大西→K ＋ S ＋ M · 右手で入る→8 大西雷神→30保持 → 9「通常へ」

右手だけで復帰できる

30を先に保持し、右上7「通常へ」を押します。8・9と入力中の保持状態を解除して0へ移動。左28にも同じ復帰を置きます。

補助面でEnter・矢印・句読点・長音・X/F/V・「ん」を入力できます。補助30を離すと8へ戻ります。

入口は右手のK＋S＋M（4・17・25）。通常の日本語綴りと重なりにくい3子音を選びます。60ms以内・直前150msの休止は仮値で、押しやすさと誤発火は実機評価が必要です。

v0.1の用途を絞る

日本語文章を右手で入力するところから始めます。数字、英文、Q/J/L、修飾キーを使うショートカットは0へ戻して従来の操作を使います。

IMEはローマ字入力を事前にONにします。配列の切り替えとIMEのON/OFFは連動しません。

右手だけで操作できますが、通信の親機は現状どおり左です。左半分の電源・接続も必要です。

06実装前に確認すること

通常レイヤー2枚に加えて、専用behaviorが必要

可変母音には「どの子音を、どの順で、まだ保持しているか」の記録が必要です。8は日本語入力、9は補助面とし、母音への変化は専用処理で扱います。単純なコンボやmod-tapの追加だけでは、この入力順序を再現できません。

  • 各キーの役割は押した時点で確定。離すまで変更しない。
  • 可変Spaceは「最後に押した、まだ保持中の子音」で決定。母音として入力したキーは候補に加えない。
  • 押下ごとに1文字を送り、保持で同じ文字をリピートさせない。
  • 母音待ち中に別キーを押したら、無出力のキーであってもSpaceの単独タップを抑止する。

ZMKのbehavior作成手順 ↗

既存コンボと低いレイヤーの衝突を解消する

現在の15＋16はLANG1、16＋17はxn、4＋14＋19はbootloaderです。新モードの重ね打ちを横取りしないよう、既存コンボを旧レイヤーに限定します。判定時間も各コンボ内へ記述します。

8・9は1・2・6より優先されるため、従来のNavや数字レイヤーを単に有効化しても上書きできません。復帰は &to 0 相当と内部状態の消去を組み合わせます。&tog 0 では8が残ります。

レイヤーの優先順位 / コンボの設定範囲

ん・促音・拗音と、音節の区切り

んはNを2回、または補助「ん」でnn。促音は子音を離して2回押すか、小書き用Xを使用。拗音は子音→Y→母音で入力します。X/F/Vは補助面で送り、その後は31を先に押す手動母音で続けます。

次の音節に移る前に、前の子音を離します。保持を続けると次の子音位置が母音に変わる場合があります。押しっぱなしで全文を打てる方式ではありません。同じ指が重なる子音連続も、前のキーを離して打ちます。
